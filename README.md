# INVEST WITH GANESH 🏡

A modern, high-performance web portal for JDA & RERA approved residential and commercial plots across Jaipur.

## 🚀 Features

- **JDA & RERA Verified Listings**: Verified plots, locations, pricing, and approval details.
- **Interactive Project Showcase**: Search, filter, and compare top projects across Jaipur (Jagatpura, Ajmer Road, Sirsi Road, Tonk Road, Vaishali West, etc.).
- **Consultation & Site Visit Booking**: Schedule free site visits and direct consultation with Ganesh Yadav.
- **Modern Responsive Design**: Built with React 19, TypeScript, Vite, and Tailwind CSS.

## 🛠️ Tech Stack

- **Frontend**: React 19, TypeScript, Vite, Tailwind CSS v4, Lucide Icons
- **Backend/API**: Express, Node.js, TSX
- **Routing**: React Router DOM v7

## 💻 Getting Started

### Prerequisites

- Node.js (v18+)
- npm or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/bad781478-lang/INVEST-WITH-GANESH.git

# Navigate to project directory
cd INVEST-WITH-GANESH

# Install dependencies
npm install

# Start the development server
npm run dev
```

### Build for Production

```bash
npm run build
```
